# Views

## Admin UI Design System and Component Uniformity
All admin views and components must strictly use the Minimalist Dark Mode with Blue Accent design system. Always extend layouts.admin and use full-width (w-full). Do not use loud gradients (purple/neon), glowing blurs, or verbose decorative text. Use bg-slate-950 for pages, bg-slate-900 for cards, border-slate-800, and bg-blue-600 for primary active accents. Maintain large typography: text-2xl font-bold for titles, text-base for sidebar nav, and text-3xl font-bold for metrics.
